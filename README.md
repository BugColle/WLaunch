GTP6なら日本語つらつら書くだけでやってくれそうなので実験

1．タスクトレイの常駐して タブでグループ分けできて アイコンクリックするだけで アプリが起動できる ランチャーアプリ作って CLaunchみたいなやつ

  ＞いきなり、まあまあなでき

2．タスクトレイ中でも右クリックで終了できるようにして
3．右クリックの終了えらべないけど

  ＞なぜかディセイブルのままで終了できない作りだった

3．リボンのタブはいらないから外して

  ＞ 自家製タブ以外に使い道のないMFCタブが入ってた

4．ドキュメントエリアも1つ固定でいいや

  ＞MDIになってたのでSDIに

5．グループの削除ができない

  ＞右クリックで消せるのに気がつかなかった

6．グループ名変更をグループ削除の下に付けてグループ名を変更できるようにして

  ＞名前が固定だったので変更できるように

7．アプリの追加を押してみアプリが選択できない
